# Once Gestión — prototipo

Prototipo web sin servidor para probar un flujo de ventas mayoristas de indumentaria.

## Funciones

- Inicio de sesión como vendedor o administrador.
- Apertura y cierre de caja.
- Venta rápida por código de producto.
- Selección de color, talle y cantidad.
- Descuento automático de stock.
- Separación entre efectivo y transferencia.
- Panel con ventas del día y productos más vendidos.
- Historial y exportación CSV.
- Datos guardados en `localStorage` del navegador.

## Prueba rápida

Códigos de ejemplo: `206`, `310`, `415`.

## Publicación con GitHub Pages

En el repositorio, abrir **Settings → Pages**. En **Build and deployment**, seleccionar **Deploy from a branch**, elegir la rama `main` y la carpeta `/ (root)`, y guardar.

## Importante

Esta versión es una demo local. Cada navegador guarda sus propios datos. Para uso real entre varios dispositivos necesita autenticación y una base de datos en línea, por ejemplo Supabase.
